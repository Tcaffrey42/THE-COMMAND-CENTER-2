COMMANDCENTER V2.16.2 STATIC LOGIN FIX

This package removes the Supabase login block for the static/demo deployment.

How to use:
1. Upload the ZIP contents at the project root.
2. In Vercel use Framework: Other.
3. Build Command: blank.
4. Output Directory: blank.
5. Install Command: blank.
6. Open the site.
7. Login screen will show admin@commandcenter.local / demo.
8. Click Login.

The app enters admin/demo mode locally. Supabase can be re-enabled later after the UI is stable.
